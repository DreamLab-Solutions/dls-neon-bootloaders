Synaptic Cosmos. La documentazione principale e le note di rilascio sono
[in inglese](../../README.md); questa sezione raccoglie la guida italiana all'uso.

- [Installazione e scelta del tema](INSTALLER.md)
- [Ripristino e rimozione](RECOVERY.md)

Il pacchetto consigliato è `dls-neon-setup-0.5.2.tar.gz`: console interattiva,
quattro temi e anteprime. Non richiede Docker né un'interfaccia grafica dedicata.
La release è una preview; finché il repository resta privato occorre avervi accesso.

## Installazione con un agente AI

Incolla nel tuo agente con terminale sul computer da personalizzare:

```text
Aiutami a installare DreamLab Boot Themes da https://github.com/DreamLab-Solutions/dls-neon-grub.
Segui docs/AI-INSTALL.md: rileva il bootloader in sola lettura, mostrami i temi,
verifica il pacchetto e presentami il piano. Verifica con me backup e live USB,
poi applica solo dopo la mia approvazione esplicita. Conserva bootloader e voci,
mantieni privati inventario e backup e non riavviare automaticamente.
```

Con Codex CLI già installato e autenticato:

```sh
codex 'Aiutami a installare DreamLab Boot Themes da https://github.com/DreamLab-Solutions/dls-neon-grub seguendo docs/AI-INSTALL.md. Ispeziona prima, mostrami temi e piano, chiedi approvazione prima di scrivere i file di avvio e non riavviare automaticamente.'
```
